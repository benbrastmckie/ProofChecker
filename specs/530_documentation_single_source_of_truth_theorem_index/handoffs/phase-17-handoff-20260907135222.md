**Two traps found the hard way, worth knowing**:
1. `typst-sync-check.sh` feeds its python through an **unquoted** heredoc, so a backtick in a
   python *comment* is command-substituted by bash. Never write backticks in that block.
2. Check 1 resolves every backticked multi-word span in `typst/**` against the Lean source, so a
   backticked shell command in a typst comment is a violation. Describe commands in prose there.
